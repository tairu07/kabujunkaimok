# 株巡回モックアップ (Kabu Junkai Mockup)

## プロジェクト概要

このプロジェクトは、プログラマーに依頼するための**UIモックアップ**です。東証上場全銘柄の日足チャートを自動再生で巡回し、お気に入り機能を備えた高速レビューツールのデザインを示しています。

## 🎯 モックアップの目的

このモックアップは、以下の機能を視覚的に示すために作成されました：

1. **チャート巡回機能**: 銘柄を自動で切り替えながらチャートを表示
2. **お気に入り機能**: 気になる銘柄を星アイコンでマーク
3. **カスタマイズ設定**: 再生速度、移動平均線、出来高表示などの設定

## 🎨 デザイン仕様

### カラーパレット
- **背景**: ダークテーマ（#0a0a0a）
- **プライマリ**: ブルー系グラデーション
- **アクセント**: 黄色（お気に入り）、緑（上昇）、赤（下降）

### お気に入りボタン
```tsx
// 実装例
<Button
  variant="ghost"
  size="icon"
  onClick={() => setIsFavorite(!isFavorite)}
```

### アニメーション
- **ホバー**: スケール 1.1倍
- **クリック**: 塗りつぶし色の変化
- **トランジション**: 200ms ease-in-out

## 🎯 ユーザーストーリー

### お気に入り機能
1. ユーザーがチャートを見ながら巡回
2. 気になる銘柄があったら星アイコンをクリック
3. お気に入りに追加された銘柄は後で一覧表示できる
4. お気に入りのみをフィルタリングして再生可能

### 再生機能
1. 再生ボタンをクリックすると自動巡回開始
2. 設定した速度（0.5〜5秒/銘柄）で自動切り替え
3. キーボードショートカットで操作可能
   - Space: 再生/停止
   - ←: 前の銘柄
   - →: 次の銘柄
